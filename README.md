# Измерение MQTT-брокеров и их моделирование в MqttY

Мета-репозиторий объединяет код, методику и результаты. **MqttBenchmark** измеряет настоящие брокеры сообщений. **MqttY** строит по измерениям профиль и исполняет модель клиентов, брокеров и сети. Скорость, задержки, ошибки и доставку сравнивают раздельно: законченный прогон ещё не означает точности модели.

Основная новая серия статьи 1 выполнена **40/40**, основная модельная сеть — **162+6**. В последующей натурной сессии статьи 1 выполнены **24/24** запуска, критерии прошли **10/12** сравнений. Эти результаты относятся к объявленным условиям, а не к произвольным брокерам и компьютерам.

## Состав репозитория

| Каталог | Назначение |
| --- | --- |
| `MqttBenchmark/` | Подмодуль натурного измерителя |
| `mqtty/` | Подмодуль симулятора и Web |
| `diss/` | Подмодуль основного текста диссертации, редактируемого автором |
| `tools/` | Запуск серий, пересчёт, проверка и подготовка отчётов |
| `docs/` | Руководства, статьи, методика и топологии |
| `reports/` | Принятые результаты, текущий статус, данные и квитанции проверок |

```bash
git clone --recurse-submodules https://github.com/EntityFX/mqtty-meta.git
cd mqtty-meta
```

Для уже существующей копии: `git submodule update --init --recursive`. Настройка окружения и команды находятся в руководствах соответствующих проектов.

Полные первичные архивы хранятся вне Git. Исторические серии и их ограничения сохранены в отчётах; устаревшие рабочие планы доступны в истории Git. Основные пути к научным данным, коду и статьям при сокращении документации сохранены.
