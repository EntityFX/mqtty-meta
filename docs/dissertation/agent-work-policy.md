# Правила работы агента

Агент измеряет, дорабатывает код, проверяет данные и готовит рабочие тексты статей по поручению пользователя. Окончательные научные выводы, согласование с соавторами, выбор издания и подача остаются за автором. Основной текст диссертации в `diss/` агент не меняет; отдельные проекты глав готовятся в мета-репозитории.

1. До опыта зафиксировать входы, критерии, оценку времени и предел. Проверить стенд и свободные ресурсы.
2. Сохранять все попытки и причины отказов. Не подменять отсутствующие точки, не менять замороженные профили, runtime и допуски ради успешного результата.
3. После долгого фонового запуска один раз подтвердить службу/PID и progress, обновить отчёт, опубликовать проверенные изменения и закончить ход для ожидания.
4. Не создавать циклический опрос, автоматические повторы и новые таймеры без прямого запроса. При отдельном поручении независимая работа может продолжаться во время расчёта.
5. По запросу статуса выполнять одну проверку; не объявлять окончание по прогнозному времени. В отсутствие связи сообщать дату последнего наблюдения.
6. В [Progress.md](../../reports/status/Progress.md) хранить актуальную сводку и чек-лист. История — в Git, данные опытов — в неизменяемых пакетах. Человеческие шаги автоматически не засчитывать.

Старые машинные снимки и хронологические записи отражают правила на дату их создания; при продолжении действуют последние поручения пользователя и [текущая цель](../../reports/status/Goal.md).
