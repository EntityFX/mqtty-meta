## Последовательность следующего блока

1. Обновить статью 2 по полному срезу: покрытие, таблицы, транзит, повторы и границы причинных выводов. Это оставшийся шаг 25; новый анализ сам по себе не считается окончательной рукописью.
2. Исправить в статье 1 формулировку про n=3, показать baseline рядом с моделью и раскрыть фактическое преобразование профиля. Числа брать из сохранённого пакета, без подгонки допусков.
3. Проверить ближайшие исследования по первоисточникам и подготовить доступный пакет воспроизведения. Указания и ссылки из обзора пока являются входом для проверки, а не автоматически проверенной библиографией проекта.
4. Заранее оформить короткий опыт по очередям/параллелизму: вопрос, фиксированные входы, единственный меняемый фактор, ранние технические проверки и предел времени. После этого принимать решение о запуске отдельной серии. Старые результаты и runtime не менять.

Отдельные научные критерии из обзора не заменяются процентом технической готовности. Закрытие шагов 23–24 означает приёмку данных и построение проверенных представлений, а не доказательство общего превосходства Relay, точности сети на реальном оборудовании или предсказательной пользы двойника вне изученной точки.
