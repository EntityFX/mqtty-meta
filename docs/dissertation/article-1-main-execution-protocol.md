# Основные 40 запусков для статьи 1

Цель: получить новые данные для прямого сравнения настоящих брокеров и моделей; технический успех не означает прохождение критериев точности.

- [x] Допуск, runtime и единое окно зафиксированы; Linux preflight и 7 тестов исполнителя прошли. Основная служба запущена, 0/40 в стартовом снимке. [Квитанция](../../reports/audits/dissertation/article-1-main-execution-v1/launch.json).
- [ ] Выполнить 12 новых натурных калибровочных запусков: четыре брокера, три повтора, 16 байт, QoS 1, 16 отправителей, один получатель.
- [ ] Независимо выделить измерительные ID, пересчитать исходы и построить настоящие микросекундные гистограммы. Рассчитать средние и выборочное стандартное отклонение по трём повторам, сохранить настоящие RTT preflight.
- [ ] Построить четыре `single-point-v1` профиля существующим калибратором, записать SHA всех входов и заморозить до контроля.
- [ ] Выполнить 12 отдельных натурных контрольных измерений, 12 моделей с seeds 42/43/44 и четыре точных повтора seed 42.
- [ ] Сохранить все попытки; технический отказ останавливает исполнение, ручное продолжение использует тот же неизменяемый deadline и только недостающие точки. Несовпадение точности не повод перезапуска.
- [ ] Пересчитать метрики двумя независимыми реализациями, сравнить с контролем также простые калибровочные средние, сохранить сводку и данные повторяемости.

Общий предел — 21600 секунд от первого старта, без сброса. Предлагаемые фазы: прогрев 1 с, подача 4 с, наблюдение 5 с, tick 10 мкс; окончательное решение фиксирует допуск до начала. Натурный брокер закрепляется за CPU 0, измеритель за 2–3; между натурными измерениями брокер запускается заново, состояние каждой попытки отдельно.

Модели предпочтительно запускать через Web. Для этой серии разрешено явное техническое исключение: новый изолированный Probe runtime, поскольку работающий Web не поддерживает новый формат, а перезапуск живого Web запрещён. Исторические runtime и профили не изменяются. Это исключение отражается в manifest; Web-паритет проверен отдельными тестами, не объявляется выполнением этих моделей через Web.

Файлы реализации: `tools/dissertation/run_matched_main_campaign.py` — исполнение и неизменяемый бюджет; `test_matched_main_campaign.py` — проверки состава, статистики, гистограмм, восстановления и бюджета.

При сравнении каждый модельный seed сопоставляется со средним трёх новых контрольных измерений данного брокера. Номера seed и натурных повторов не создают парности. Дополнительно показываются диапазоны натурных повторов и ошибка простой таблицы калибровочных средних. Квантили задержки в профиле — средние трёх квантилей, распределение модели — объединённые бины с их настоящим числом событий. Эти два объекта не смешиваются.

Локально подготовлены runner и семь тестов; проверено чтение создаваемых агрегатов существующим C#-калибратором. Проверка формата с повторённым историческим raw и явно синтетическим RTT является только тестовым примером и не входит в научные 40 запусков.
