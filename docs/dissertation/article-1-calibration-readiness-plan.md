- [x] Введён `single-point-v1` в калибраторе, читателе и CLI; в профиле явно фиксируется единственный точный режим. Прежние проверки полной/compact-сетки сохранены.

- [x] Синтетический эмпирический профиль одинаково исполнен прямым runner и Web-адаптером, научные файлы совпали побайтно; неподдерживаемые режимы отвергаются. Это локальная проверка кода, новый Linux runtime ещё не установлен.
