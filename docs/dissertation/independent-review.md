# Задание независимому проверяющему: шаг 07

Технический пересчёт завершён: 576 выбранных измерений согласуются с журналами. Следующая задача — передать проверку другому сотруднику, чтобы он по сохранённым материалам проверил основные определения и несколько результатов. Этот документ подготовлен агентом; он не является независимым заключением.

## Что передать сотруднику

- Commit мета-репозитория со всеми подмодулями и пакет `reports/audits/dissertation/foundation-v2`.
- Контракт `docs/overview/measurement-contract.md` и инструкцию `docs/dissertation/foundation-reproduction.md`.
- Доступ только на чтение к первичным архивам и полной сводке `audit-results.json` на диске доказательств.
- [24 выбранных архива](../../reports/audits/dissertation/independent-review/selected-24.json) и [реестр с этими архивами в начале](../../reports/audits/dissertation/independent-review/ordered-archive-registry.json).

Выборка содержит по одному архиву каждого брокера × стадии calibration/validation × QoS, всего 24. В каждой группе выбран максимальный delivery loss, затем failure и число попыток. Это заранее записанная диагностическая выборка по уже известным данным, а не случайная выборка; она не даёт оценки вероятности ошибки всей кампании.

Реестр по составу совпадает с исходными 592 записями; изменён только порядок. Он не заменяет исходный реестр кампании. ID, SHA-256 архивов и ожидаемый `result.json` указаны в списке выборки.

## Порядок проверки

1. Записать имя проверяющего, проверенный commit, ОС, Python и пути к данным. Не включать учётные данные.
2. Выполнить `foundation.py verify` по инструкции, сверить хэш полной сводки. Сохранить реальный stdout, stderr и код выхода.
3. Прочитать формулы попыток/исходов/доставок и самостоятельно проверить пример A=100, C=80, Dс=60, Dф=10, T=2. Ожидаются RPS 50/40, failure=0,20, deliveryLoss=0,25, полнота D/A=0,70. Если получились взаимодополнительные loss и D/A, знаменатели перепутаны.
4. Проверить по коду и малым тестам верхний ранг квантиля `ceil(p×n)`, отсутствие ACK для QoS 0 и отличие среднего трёх p99 от квантиля объединённого потока.
5. Повторить чтение 24 архивов в новом каталоге на диске доказательств командой ниже. Входные данные и прежний результат не изменять.
6. Для нескольких выбранных ID сопоставить attempt, ровно один outcome и первую доставку; проверить исключение ID прогрева. Сверить один временной знаменатель с монотонными tick и частотой timestamp.
7. Для одного QoS 1/2 вручную проверить нормировку EST в общей точке четырёх брокеров; для QoS 0 подтвердить отдельную адаптацию EST*. CPU, доставочные доли и квантили должны соответствовать одному определению и набору повторов.
8. Сверить таблицу точности и выводы с результатами: 203/288 holdout проходят все применимые критерии; первичный аудит не превращает остальные 85 запусков в прошедшие.
9. Составить заключение: что повторено, что не удалось, какие расхождения найдены, какие показатели допустимо использовать. При расхождении сохранить файлы и точные команды, не изменять пороги и не перекалибровывать профиль.

Команда для нового пересчёта на Linux из корня мета-репозитория:

```text
python tools/dissertation/run_native_audit.py --registry reports/audits/dissertation/independent-review/ordered-archive-registry.json --native-evidence reports/data/native-evidence.json --output /path/to/evidence/independent-review --mount-root /path/to/evidence --workers 2 --limit 24
```

Пути в реестре должны соответствовать доступным архивам на этой машине. При переносе диска создаётся отдельный явно помеченный реестр с теми же SHA-256, а не изменяется оригинал. `--mount-root` указывает на точку монтирования; output и архивы располагаются внутри неё. Входной набор native остаётся полным (576 измерений), `--limit 24` ограничивает только эту проверку. Итог является выборочной проверкой, не новой полной кампанией.

Повторный запуск исходного верификатора другим человеком проверяет его запускаемость и результаты по инструкции, но может повторить ошибку алгоритма. Поэтому содержательная сверка формул, ID и нескольких исходных событий обязательна. Она не заменяется словом «скрипт завершился».
