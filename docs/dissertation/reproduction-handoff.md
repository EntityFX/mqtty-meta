## Проверка трёх полных примеров

Распаковать ZIP в новый каталог и выполнить из любого рабочего каталога:

```text
python <каталог-распаковки>/verify_all.py
```

Проверено на Python 3.12.10; нужны только стандартные модули. .NET, работающий брокер, закрытый подмодуль `diss` и исходный checkout не требуются. Для сетевого примера ожидается: 10000 исходных попыток, 40000 ожидаемых и уникальных доставок, недоставка 0, исходный RPS 1000, 30000 экспортов. Счётчик проверяет ID, payload, гистограммы и сохранённые SHA. На свежей распаковке проверка прошла; подмена SHA в manifest была отвергнута.

В пакет добавлены `control.Aedes.r1` и `model.Aedes.r1`: настоящих завершений 70395, модельных 68492, p99 соответственно 2,1368 и 2,1900 мс. Это индивидуальные примеры; они не подменяют сравнение каждой модели со средним трёх контролей в статье. Сетевой пример — `matrix.line.federation.q0.r1000.w10.s42`. Полная матрица в ZIP не включена. Старые ссылки на дополнительные отчёты в рукописях разрешаются через мета-репозиторий; ZIP не является зеркалом всего репозитория.

Дополнительно включены четыре калибровочные гистограммы и определения протокольного минимума. Та же команда пересчитывает их веса: у Mosquitto 2002/257092 наблюдений ниже минимума и 2297/257092 с нулевым остаточным временем. Это проверка сохранённых интервалов, не полный пересчёт исходных событий всех калибровок. Рукописи в ZIP сверены побайтно с текущей редакцией. Прежние пакеты и квитанции сохранены.
