## Проверка одного полного примера

Распаковать ZIP в новый каталог и выполнить из любого рабочего каталога:

```text
python <каталог-распаковки>/verify_example.py
```

Проверено на Python 3.12.10; нужны только стандартные модули. .NET, работающий брокер, закрытый подмодуль `diss` и исходный checkout не требуются. Ожидаемый результат: 10000 исходных попыток, 40000 ожидаемых и уникальных доставок, недоставка 0, исходный RPS 1000, 30000 экспортов. Счётчик проверяет ID, payload, гистограммы и сохранённые SHA. На свежей распаковке проверка прошла; подмена SHA в manifest была отвергнута.

Это пример `matrix.line.federation.q0.r1000.w10.s42`, а не вся матрица и не натурная проверка статьи 1. Старые ссылки на дополнительные отчёты в рукописях разрешаются через мета-репозиторий; ZIP не является зеркалом всего репозитория.
