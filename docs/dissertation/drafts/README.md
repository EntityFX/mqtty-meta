# Проекты разделов диссертации

Связные русские тексты для редакции автором. Это подготовительные материалы в мета-репозитории; исходные главы в `diss` не изменены.

| Проект | Содержание | Основание | Шаг основного плана |
| --- | --- | --- | --- |
| [Глава 1](chapter-1-problem-and-methods.md) | Постановка задачи, ближайшие подходы и границы утверждений | Проверенные источники двух статей и матрица положений | 30 |
| [Глава 2](chapter-2-measurement.md) | Настоящий стенд, события, показатели, измерения и исторический EST | Новая серия статьи 1; отдельный прежний отчёт MqttBenchmark | 31 |
| [Глава 3](chapter-3-relay.md) | Физические и логические графы, Relay, федерация, конечность и доставка | Контракт, доказательства, полные 162 основных запуска и шесть повторов | 32 |
| [Глава 4](chapter-4-validation.md) | Роли программ, профиль, фазы и тики, точность, повторяемость, перенос | Новая серия 40/40; отдельные исторические проверки и аудит ускорения | 34 |

Новая серия статьи 1, прежние серии настройки/контроля, короткая сетевая демонстрация и основная длинная сетевая программа — разные наборы. Их числа и знаменатели нельзя объединять. Глава 3 теперь использует окончательный пересчёт 162+6; прежний срез 106 сохранён в исторических отчётах.

Перед переносом в диссертацию нужно согласовать научные выводы и личный вклад, соединить проекты с остальным текстом глав, обновить библиографию и нумерацию и выполнить сквозную сборку. Полные сетевые результаты уже приняты; повторно их запускать для этой редакции не требуется. Подготовка этих файлов сама по себе не закрывает шаги 30/31/32/34. Независимое человеческое чтение остаётся отдельным условием. [Карта переноса](integration-map.md) связывает проекты с существующими разделами LaTeX и перечисляет проверки интеграции.

Схемы сети взяты из [каталога топологий](../../topologies/README.md); рисунки измерений — из сохранённого пакета новой серии. [Квитанция v2](../../../reports/audits/dissertation/chapter-drafts-v2/verification.json) относится к текущей редакции; [квитанция v1](../../../reports/audits/dissertation/chapter-drafts-v1/verification.json) сохранена для прежних проектов. [План обновления](../chapter-refresh-plan.md), [крупный план](../next-delivery-block-plan.md) и [общий прогресс](../../../reports/status/Progress.md) содержат оставшиеся действия.
