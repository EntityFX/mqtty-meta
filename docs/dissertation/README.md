| Документ | Назначение |
| --- | --- |
| [Аудит готовности](readiness-plan.md) | Научные пробелы, проверенные результаты и условия готовности к предзащите |
| [План двух статей и завершения диссертации](articles-and-work-plan.md) | Последовательные шаги, результаты и оценки в человеко-днях |

Проверяемые материалы аудита хранятся в [reports/audits/dissertation](../../reports/audits/dissertation/). [Снимок статуса работы агента](../../reports/status/dissertation-agent-progress.json) описывает последнее наблюдение, а не живой статус Linux-процесса.

Основной текст диссертации остаётся в `diss/dissertation.tex`, `diss/Dissertation` и `diss/common`. Из подмодуля перенесены только материалы папки `doc`; главы, библиография, рисунки, публикации и сборка диссертации сохранены.

Исторические проверки установки отделены от основной кампании: [архив отчётов](../../reports/history/README.md). Актуальные результаты измерений и моделей: [общий индекс](../../reports/README.md).
