# Десять брокеров через транзит

Копия схем сохранённого опыта; брокеров 10, дополнительных сетевых узлов без брокера 1. Полезная нагрузка и MQTT-параметры приведены в [отчёте](../../../../reports/mqtty/federation/Federation-ten-brokers.md). Это конкретная схема опыта, не готовый универсальный пресет Web.
