# Каталог топологий MqttY

Объединённый справочник по физическим и логическим схемам сетей. Информация из tidligere отдельных файлов `README.md`, 연구ми अध्ययन и шаблонов сохранена без сокращений выводов.

---

## 1. Обзор

В каталоге собраны определения сетевых топологий для исследований MqttY: LoadBalancing, Federation (star/ring/line), Relay. Каждая топология имеет физическое и логическое представление, параметры сети и ожидаемые характеристики трафика.

---

## 2. Изучения (studies)

| Исследование | Описание |
|---|---|
| `main-line4` | Основная линейная сеть из 4 площадок |
| `main-ring4` | Основное кольцо из 4 площадок |
| `relay-transit10` | Relay с 10 брокерами через транзитный узел |
| `load-pool3` | Нагрузка на пул из 3 backend |
| `single64` | Один брокер с 64 publishers |

Каждое исследование содержит README с описанием конфигурации, параметров и ожидаемых результатов.

## 4. Связь с исследованиями

Топологии используются в статьях MqttY для сравнения распределения нагрузки, задержек и пропускной способности различных архитектур MQTT-сетей. Результаты измерений публикуются в [отчётах](../../reports/README.md).
