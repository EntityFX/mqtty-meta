**Цель:** запускать согласованную одиночную модель статьи 1 из Web с теми же исходными данными и результатами, что у существующего исполнителя.

**Средства:** C#, существующие Contracts/Engines/Web и тестовые проекты; короткая Python/браузерная проверка Linux.
