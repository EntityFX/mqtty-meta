# MqttBenchmark: натурные измерения

Основная инструкция — [runbook](runbook.md): подготовка машины, сборка, брокеры, полная и сокращённая программа, наблюдение за прогрессом и передача результатов. Она заменяет разрозненные страницы установки и отдельных этапов.

| Задача | Документ |
| --- | --- |
| Определить показатели и временные окна | [Метрики](metrics.md), [общий контракт](../overview/measurement-contract.md) |
| Проверить файлы, события и происхождение результата | [Формат артефактов](artifact-format.md) |
| Разобрать особенности ActiveMQ | [Особенности брокера](brokers/ActiveMQ.md), [результаты](../../reports/mqtt-benchmark/ActiveMQ-diagnosis.md) |
| Найти уже выполненные сравнения | [Принятые результаты](../../reports/README.md) |
| Решить, нужен ли ещё запуск | [План завершения](../plans/completion.md) |

Завершённый процесс не означает прохождения научного допуска. Исходные неудачи, события и контрольные суммы сохраняются; полный эксперимент не повторяется без конкретного вопроса. Исторические инструкции для прежних версий доступны в [архиве](../../reports/history/README.md).
