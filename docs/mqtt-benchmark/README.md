# MqttBenchmark: измерение реальных брокеров

MqttBenchmark создаёт настоящую MQTT-нагрузку, управляет выбранным стендом и сохраняет первичные события, телеметрию и агрегированные наблюдения. MqttY использует эти наблюдения отдельно: сборка профиля не запускает реальный брокер.
