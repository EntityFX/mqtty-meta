# Документация проекта

Документация хранится в мета-репозитории. Исходники приложений находятся в подмодулях; результаты экспериментов — в `reports`. Начните с раздела, который соответствует вашей задаче.

| Раздел | Что в нём находится |
| --- | --- |
| [Обзор проекта](overview/README.md) | Общее руководство, архитектура, ответственность приложений и ответы на вопросы |
| [MqttBenchmark](mqtt-benchmark/README.md) | Подготовка машин, установка брокеров, натурные измерения, метрики и автоматизация |
| [MqttY](mqtty/README.md) | Симулятор, калибровка, Relay, балансировка соединений, федерация и Designer |
| [Диссертация и статьи](dissertation/README.md) | Готовность исследования, последовательный план двух статей и правила воспроизводимости |
| [Отчёты](../reports/README.md) | Результаты по брокерам и моделям, проверка доказательств и исторические материалы |

Руководства объясняют, как работать с системой. Отчёты описывают конкретные опыты и их ограничения. JSON/CSV, графики и реестры в `reports/data` сохраняют происхождение результатов; архивы первичных журналов хранятся вне Git.

Исполняемые примеры и тестовые входы, необходимые отдельному проекту, остаются рядом с его кодом. README приложений содержат краткое описание, состав и быстрый запуск; ссылки ведут к подробным руководствам. Основной текст диссертации и её сборочные файлы находятся в `diss`.

При изменении структуры проверьте ссылки командой `python tools/documentation/check.py` из корня мета-репозитория. Генераторы отчётов используют актуальные каталоги; для результатов старого генератора выполните `python tools/documentation/publish.py --reports reports`. Эта команда обновляет размещение документов и их контрольные суммы, проверяя сохранность научных данных. Исходные пути и контрольные суммы переноса сохранены в `reports/data/documentation-layout-v1/manifest.json`.
