## Команды воспроизведения

Все выходные каталоги ниже должны быть новыми. Полные raw находятся вне Git; их происхождение и SHA указаны в [квитанции переноса](../article-1-main-execution-v1/raw-transfer.json).

```text
python -m unittest discover -s tools/dissertation -p test_audit_matched_main_results.py -v
python -m unittest discover -s tools/dissertation -p test_matched_main_campaign.py -v
python tools/dissertation/audit_matched_main_results.py --root <корень-перенесённых-raw> --output <новый-каталог-пересчёта>
python tools/dissertation/render_matched_main_figures.py --root <корень-перенесённых-raw> --output <новый-каталог-рисунков>
```

Для пересчёта нужна стандартная библиотека Python; для рисунков дополнительно Matplotlib. Скрипты не обращаются к Linux и не запускают измерения. При повторной отрисовке двоичная идентичность PDF не требуется: время создания и версия библиотеки могут отличаться. Проверяются числа, фазы и вид графиков.

## Границы результата

12/12 моделей проходят допуски в четырёх заданных условиях. Простые калибровочные средние также проходят — преимущество симуляции для этих агрегатов не показано. Четыре точных повтора подтверждают заданные семь научных компонентов, не весь каталог. Действующий Linux Web основную серию не исполнял.

Это программная арифметическая проверка и техническая сверка текста. Она не заменяет человеческую научную рецензию, оценку достаточности вклада и оформление для выбранного издания.
