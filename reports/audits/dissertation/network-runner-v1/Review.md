# Локальная проверка оркестратора сетевой программы

Реализованы stage, раздельный запуск этапов, verified resume и явное восстановление прерванной попытки. Приложение MqttY, текущая Linux-серия, её профили и входы не менялись. Linux в этом блоке не опрашивался.

| Проверка | Результат |
| --- | --- |
| Все тесты инструментов диссертации | 68/68 |
| Из них тесты нового оркестратора | 14/14 |
| Окончательный локальный тест настоящего MqttY CLI | 15/15, технических ошибок 0 |
| Покрытие окончательного теста | 9 случаев: три режима × три QoS; 3 опорных случая; 3 точных повтора |
| Scientific summaries и первичные журналы повторов | Совпали побайтно |
| Resume | Завершённые симуляции повторно не запускались |
| Новые Linux-опыты научной программы | 0 |

Тесты проверяют подмену входов/runtime, повреждение и пересчёт raw, неверную запись решения по pilots, неполное покрытие, потерю индекса, живую незавершённую попытку, timeout/RSS/диск, потерю mount, взаимное исключение, остановку следующих задач и сохранение старого отказа при явном retry.

Для нагруженного Relay используется отдельный пересчёт: невозможность получить все исходные сообщения у helper не делает неполный экспорт автоматически техническим отказом. При этом проверяются payload, пары доставки, знаменатели, квантили, drain, отсутствие повторного экспорта и неправильного источника. Идеальная формула стоимости применяется только при выполнении её условий. Исторический верификатор прежних результатов не менялся.

Окончательная проверка выполнена на Windows с настоящим MqttY CLI. Имитирован только признак mount; чистота исходников Git, свободное место, host/runtime, процессы и математическая проверка были реальными. Признак mount нельзя таким способом считать проверенным на Linux; cgroup также не проверялся.

На предыдущих версиях выполнены два локальных теста по 15/15. Все три снимка сохранены: [первый тест](initial-smoke-verification.json), [промежуточный](intermediate-smoke-verification.json), [окончательная проверка](smoke-verification.json). Итого 45 локальных функциональных симуляций, **ни одна не засчитана в 30 pilots / 162 + 6 научной программы**. Полные тестовые выходы остаются в игнорируемом каталоге artifacts; это воспроизводимая проверка кода, а не новые диссертационные наблюдения.

Остались Linux-preflight, проверка реального mount/cgroup и проведение pilots после текущей чувствительности. Достаточность прогрева/окна и динамика завершений ACK не подтверждаются локальными случаями на 6 мс.

Запуск проверки: `python tools/dissertation/network_runner_smoke.py --work-dir MqttBenchmark/artifacts/<новый-каталог>`. Нужны чистые исходники и собранный Federation.App. Инструкция эксплуатации: [network-runner.md](../../../../docs/dissertation/network-runner.md).

Отдельный [снимок счётчиков](progress-counters.json) показывает покрытие каждого этапа. История попыток отделена от текущих неустранённых ошибок; тест подтверждает сохранение одного отказа после успешного retry (два опыта, три попытки).
