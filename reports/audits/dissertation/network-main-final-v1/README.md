# Полная приёмка основной сети

Источник: неизменяемая программа `network-full-3h-v1`, 162 точки + 6 выбранных повторов. Новых симуляций в этой приёмке нет.

- `transfer-verification.json` и `source-file-index.json` — 4412 файлов с размером и SHA, архив вне Git.
- `raw-recount/verification.json`, `comparison.csv`, `condition-stats.json`, `cases/` — независимый пересчёт всех 162 точек существующим счётчиком. Его историческое поле `mainCampaignComplete=false` не менялось; отдельная полная приёмка дана в `acceptance.json`.
- `acceptance-procedure.py`, `registry_gates.py`, `test_registry_gates.py` — строгий допуск и фактически выполненная проверка шести повторов; семь тестов, в том числе отсутствие повторов/точек и неверный SHA. Первоначальная ошибочная проверка обязательности файла транзита и её исправление записаны в `acceptance-attempts.json`.
- `transit.csv` — 54 проверки разностей счётчиков физического транзита; байты этого уровня не равны topic+payload.
- `figures/`, `cost-figures/` — четыре просмотренных рисунка в SVG/PDF/PNG. Скрипты построения читают сохранённые данные; палитры проверены academic-figure.
- `topologies/` — 18 исходных SVG/Mermaid с SHA источника, включая отдельные маршруты Relay и федерации.
- `package-verification.json` — заключительная сверка чисел таблиц и рисунков, ссылок, хэшей и защищённого LaTeX.

Полные архивы остаются вне Git. После анализа по просьбе пользователя удаляются только распаковки с подтверждёнными архивными копиями; [отдельная квитанция](../temp-cleanup-20261029/receipt.json) описывает фактически выполненную очистку. Путь `raw-002` в ранних квитанциях — расположение на момент проверки. Для повторного пересчёта сначала распакуйте сохранённый архив в новый каталог.

```text
python tools/dissertation/audit_network_main_results.py --root <распакованный-каталог> --output <новый-каталог-пересчёта>
python -m unittest discover -s reports/audits/dissertation/network-main-final-v1 -p test_registry_gates.py -v
```

`acceptance-procedure.py` является сохранённой процедурой данного исполнения. Для нового расположения данных замените `root`, `out`, `previous` и путь к квитанции переноса, сохранив проверки; входы нельзя подменять соседними точками. `transfer-procedure.py` показывает выполненную проверку архива, распаковку и SHA всех файлов; повторное исполнение требует нового пустого каталога. Хэши процедур сохранены отдельно. Установленный Linux Web эту научную программу не исполнял; приёмка не подтверждает натурную точность или независимое человеческое рецензирование.
