Проверены три места вызова выборки в брокере: ошибка публикации, задержка обработки и недоставка при рассылке. ## Повторение проверки

Команда из корня репозитория в данном окружении:

```powershell
& 'C:/Users/entityfx/.mqtty-tools/python/python.exe' -X utf8 reports/audits/dissertation/model-method-20261030/verify_sources.py
```

[Скрипт](verify_sources.py) читает исходники через `git show`, исходные JSON и документы. Он записывает только MD/TSV в этот каталог. До редактирования однократно вызван `--capture`, чтобы сохранить снимки исходников и [хеши защищённых частей текста](protected-text.tsv); повторно захватывать базу после правок не требуется. Проверка без аргументов сравнивает с этой базой аннотацию и раздел 1, всё начиная с раздела 3 статьи, историческую часть заметок и runtime-манифест. Она также проверяет существование относительных ссылок в трёх затронутых документах. Текущий результат — в [verification.md](verification.md).

Для двух изменённых существующих документов также выполнен `git -c core.whitespace=cr-at-eol diff --check -- docs/dissertation/articles/article-1-twin-validation.md reports/analysis/Article-1-technical-notes.md`: ошибок нет. Параметр учитывает принятые в рабочей копии окончания строк CRLF. Самопроверка раздела методики выполнена по руководству навыка: входы и определения предшествуют алгоритму, порядок операций восстанавливается из псевдокода, каждый блок связан с исходником, допущения и ограничения названы явно. Такая проверка ясности не является независимым научным рецензированием.

## Подтверждённые уточнения

- Ёмкость равна `attemptedRps×(1−rateRejectionRate)`, а не безусловно целевой завершённой скорости. В нынешних четырёх профилях обе доли ошибки нулевые, и эти скорости равны; научные числа не пересчитывались.
- Резерв обновляется до проверки ошибки и не возвращается при её срабатывании. Задержка выбирается только для допущенной публикации; профильная недоставка применяется позже при рассылке каждой подписке.
- При нынешнем режиме RTT определяет настройку транспорта через ограничение по минимальному наблюдению. Полученный идеальной пробой P вычитается из выборки исходной CDF; сохранённая CDF с вычетом QoS×RTT имеет более низкий приоритет и не используется в этом пути.
- Назначения выборок различны, но статистическая независимость не установлена. Признаки недоставки не обусловлены выбранной задержкой; совместное распределение и временные зависимости настоящего тракта по этим входам не восстановлены.

Техническая неоднозначность R2 получила проверяемое описание. Влияние зависимости потерь от задержки, физическая декомпозиция RTT, альтернативы правилу max, соответствие DLL исходникам отдельным бинарным аудитом и научное утверждение рукописи остаются за пределами этой проверки. Ответ на рецензию и общие статусы ведёт основной агент.
