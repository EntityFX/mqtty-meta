# Проверка механизма Relay и статической федерации

Техническая проверка завершена. Исходные эксперименты и работающая серия чувствительности на Linux не изменялись. Дополнительных длительных расчётов не запускалось.

| Проверка | Результат |
| --- | --- |
| Целевые тесты MqttY | 39/39, ошибок и пропусков 0 |

| Первичные журналы сохранённых сетевых опытов | 72/72: 54 кольцо + 18 Relay с транзитом |
| Из них идеальная модель | 36/36: 27 кольцо + 9 транзит |

| Сохранённые повторения scientific summary | 12/12 совпали побайтно |
| Критические дефекты в проверенном механизме | Не обнаружены в пределах этих тестов и опытов |

Python пересчитал публикации, пары доставки, полноту/недоставку, гистограммы и квантили, RPS, события drain, пересылки и payload. Дополнительный контроль сверил физические GraphML, размещение клиентов и условия групп сравнения. В идеальных опытах подтвердились комбинаторные формулы стоимости пересылки и подавления повторов.

**Обнаруженные ограничения:** разные число брокеров и служебных соединений; собственная FIFO федератора при непосредственном вызове Publish в Relay; короткое измерительное окно; выход сетевого трафика за условия профиля Mosquitto. Десятиброкерная серия содержит только Relay. Равный аппаратный бюджет, установившаяся производительность, натурная точность федерации и самоорганизация не подтверждены.

Условия и формулы зафиксированы в [техническом контракте](../../../../docs/dissertation/network-model-contract.md). [Машинное заключение](verification.json) содержит отдельные результаты 72 опытов, SHA summaries, происхождение исторического runtime и хэши проверяющего кода. [TRX](federation-review.trx) сохраняет результат текущих тестов. Тесты текущих исходников и проверка исторических журналов — два разных подтверждения; старые результаты не переименованы в новый эксперимент.

Технические критерии шагов 19–20 выполнены: графы/условия явно определены, различия ресурсов учтены, механизм проверен тестами и первичными журналами. Научное чтение автором и независимым сотрудником не заменено. Более длинная программа, pilot и новая матрица остаются шагами 21–24.
