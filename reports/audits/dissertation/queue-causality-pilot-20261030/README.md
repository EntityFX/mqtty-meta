# Локальная приёмка пилота q1/1024

- collect.py — выполненная однократная процедура переноса. Создаёт новые каталоги, не перезаписывает старые; нового измерения не запускает.
- transfer.json и source-file-index.json — архив, пути, размеры/SHA 83 файлов, повторная проверка 281 исходного файла на Linux.
- accept.py и acceptance.json — локальный пересчёт, отдельная арифметика пар ID/receiver, проверка pinned runtime/config, однофакторности, графов, payload, фаз и научных seals.

Полный архив и распаковка находятся вне Git по пути из transfer.json. Повторный локальный пересчёт: `python -B reports/audits/dissertation/queue-causality-pilot-20261030/accept.py`. Новое местоположение данных требует отдельной квитанции путей с сохранением исходных SHA. Не повторять collect.py в существующие каталоги.

Источники совпали по ID, размещению и расписанию относительно начала измерения. Абсолютный старт подачи и поле времени payload различаются из-за разного warmupDrain; это не побайтово одинаковый trace. Вывод ограничен всем коротким эпизодом с данным параметром очереди, не причиной потерь основной серии. Один seed, без независимого человеческого повторения.
