# Переключение терминального монитора

Добавлен режим network с явными параметрами study/service. Сохраняются пользовательские проверки hd250, Web, CPU/RAM/температуры и мощности; прежний dashboard sensitivity доступен отдельно. Network показывает 162 основных и 6 повторов, исключая 30 сохранённых пилотов и 54 необязательные диагностические точки из знаменателя.

14 тестов проверяют прежнюю статистику и новый вложенный формат workers/jobs, исключение повторных попыток из счётчиков и разделение предупреждений/технических ошибок. Проверена одна реальная консольная рамка на Linux. Перезапущен только интерактивный SSH-монитор, без смены научного runtime, входов и процессов кампании. SHA источника и PID находятся в reports/status/network-monitor-restart.json.

Повторный запуск:

```text
python3 /tmp/monitor_sensitivity_network.py --campaign network --study /run/media/entityfx/hd250/mqtty-evidence/network-full-3h-v1 --service mqtty-network-full-3h-v1.service
```

Для одной рамки добавить --once. Web использует свой реестр задач; внешний CLI-контроллер пока не подключён к Web как источник состояния.
