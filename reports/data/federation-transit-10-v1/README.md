# Данные опыта с десятью брокерами и транзитной сетью

[Отчёт](../../mqtty/federation/Federation-ten-brokers.md) относится к отдельной программе Relay: 10 брокеров, 160 исходных publishers, 10 subscribers и один сетевой узел transit без MQTT-приложений. Физическая сеть — звезда; логическая — 90 направлений «каждый с каждым». Импортированные сообщения не экспортируются повторно.

[Программа](study-plan.json) фиксирует commit MqttY, хэши DLL, профиля и сценариев. [CSV](runs.csv), [сводки с сетевыми доказательствами](runs.json) и [агрегаты](aggregates.json) содержат 18 основных запусков. [Проверка](verification.json) отдельно показывает шесть повторов и предупреждения о недоставке. Повторы не добавляются к трём seeds при расчёте интервалов.

Проверяются первичные публикации и получения, пары ID–subscriber, сохранность payload, пересылки только с исходной площадки, гистограммы и формулы RPS. Для каждого направления PathFinder должен вернуть `siteA → transit → siteB`. Сетевые счётчики сравниваются по снимкам до нагрузки и после drain: соединения, подписки и прогрев исключены. Наличие маршрута и фактическое прохождение пакетов проверяются раздельно. Для идеальной модели проверяются все 2000 доставок и 1800 пересылок.

[Проверки программ](validation-tests.json) включают 316 тестов MqttY без длительных тестов и семь Python-проверок. [Повторение отчёта](report-reproduction.json) фиксирует сравнение файлов по байтам. SVG физической сети показывает transit, SVG логической — матрицу направлений; Mermaid сохраняет все связи.

[Квитанция архива](archive-receipt.json) содержит путь на внешнем диске, размер, SHA-256 и результат повторного чтения. Полные журналы, snapshots, конфиги, runtime и тестовые протоколы хранятся вне Git. Распакованные исходники сохраняются. [Реестр публикации](publication-sha256.json) проверяет компактные данные и Markdown отчёта.

Прежние результаты с другими топологиями сохранены и не объединены с этим опытом. Профиль Mosquitto используется строго в точке N=16; дополнительный fanout и пересылки натурно не калибровались. Большая модельная недоставка не доказывает такие же потери настоящего брокера. Single с N=160 не запускался по этому профилю: нужной точки нет.
