# Проверка полносвязного Relay

В этой серии Relay соединяет каждый брокер со всеми остальными: 6 направлений для трёх брокеров, 12 — для четырёх. Каждый узел экспортирует только свой исходный поток; импорт доставляется локальным подписчикам без повторного экспорта. Физическая сеть остаётся кольцом. Проверки линии и ромба выполнены отдельно в тестах.

[Основной отчёт](../../Federation-study.md) содержит результаты 54 симуляций, графики и топологии. [Программа](study-plan.json) фиксирует версии и входы. [JSON](runs.json), [CSV](runs.csv) и [агрегаты](aggregates.json) позволяют проверить таблицы. [Проверка](verification.json) подтверждает пересчёт первичных журналов и побайтное совпадение шести повторов. [Предупреждения](warnings.json) отделены от технических отказов.

[Тесты](validation-tests.json): 319 различных проверок C# и пять проверок Python прошли; повторно выполненные тесты федерации не прибавлены к числу различных проверок. В C# проверены QoS 0/1/2, линия, кольцо и ромб, отсутствие subscribers, экспорт каждому другому брокеру ровно один раз и отсутствие повторного экспорта импорта. Python независимо проверяет место отправки, адресатов, темы, уникальность пересылок, payload, доставки, гистограммы, drain и формулы RPS.

[Повторение генерации отчёта](report-reproduction.json) подтверждает побайтное совпадение 34 файлов. [Версии генераторов](reporting-verification.json) фиксируют их хэши. В опубликованных SVG Relay убраны избыточные подписи источников на пересекающихся стрелках; пути и направления сохранены. Первичные SVG/Mermaid и GraphML остаются в архиве.

[Сравнение программ](protocol-comparison.json) показывает: все 36 сводок single и federation остались прежними; Relay проверен заново. [Отчёт с прежними деревьями](../../Federation-study-bfs.md) сохранён. Эти серии не объединяются в статистические повторы.

[Квитанция архива](archive-receipt.json) содержит путь на внешнем диске, SHA-256 и результат проверки на Linux. Полный архив хранится вне Git: первичные журналы публикаций, получений и пересылок, payload, конфиги, snapshots профиля, runtime, команды, фазы, графы и реестры SHA-256. Распакованные исходники сохраняются. [Реестр публикации](publication-sha256.json) проверяет компактные данные и Markdown отчёта.

В идеальной модели доставка полная. В опытах с профилем Mosquitto условные потери исходной профильной точки применяются на нескольких этапах, поэтому возможна большая итоговая недоставка. Это исследовательское применение профиля вне его условий калибровки; оно не подтверждает такие потери у настоящего Mosquitto. CPU/RSS, EST, самоорганизация и отказоустойчивость не проверялись.

Для повторения нужны исходники MqttY и версии из программы, .NET 6 runtime, Python и Matplotlib. Отдельный опыт: `run --config <опыт>/run-config.json --output <новый-каталог>`. Вся серия: `python tools/federation/study.py run --work-dir <новый-каталог>`. Проверка: команда `verify` того же сценария. Итоговый отчёт: `python tools/federation/report.py --work-dir <каталог>`.
