# Доказательства приёмочной серии федерации

Основной набор: **54 симуляции и 6 повторов**. Технических отказов нет. Полнота доставки оценивается отдельно от завершения процессов. Результаты описаны в [сравнительном отчёте](../../Federation-study-bfs.md).

## Какие данные опубликованы

- [План и версии исходников](study-plan.json): commit MqttY, SHA-256 профиля и исполняемых DLL, параметры и список точек.
- [Научные сводки](runs.json), [CSV](runs.csv), [средние и интервалы](aggregates.json).
- [Проверка 54 точек и шести повторов](verification.json), [фактические предупреждения](warnings.json), [проверки программ](validation-tests.json).
- [Версии и хэши генераторов отчёта](reporting-verification.json), [целостность публикации](publication-sha256.json).
- Физические и логические топологии SVG/Mermaid: для обоих семейств и всех трёх режимов. Они проверяются по GraphML выполненных опытов.

Первичные журналы каждой публикации, получения и попытки пересылки, payload, конфиги, профильные snapshots, runtime, stdout/stderr и per-run реестры SHA-256 сохранены в полном архиве. Они позволяют заново вычислить пары ID–subscriber, потери, задержки, гистограммы, drain и формулы RPS. Исходные завершения берутся из отдельных publisher-счётчиков, проверенных тестами; не из суммы всей работы брокеров и не из одного исчезновения pending.

## Внешние архивы

[Квитанция основного архива на hd250](archive-receipt.json) содержит путь, SHA-256, размер, UUID файловой системы и результаты проверки файлов. Архив прочитан обратно локально, затем проверен на Linux после переноса. Распакованные исходники автоматически не удаляются. Архивы в Git не добавляются.

Предварительная серия с прежней отрисовкой сохранена отдельно: [её квитанция](initial-archive-receipt.json). После изменения только SVG/Mermaid выполнена новая полная серия; [сравнение](cross-version-comparison.json) подтверждает побайтное совпадение всех 54 основных scientific summaries между сборками. Предварительные запуски и отдельные pilots не прибавляются к основному покрытию и не используются как дополнительные статистические повторы. Основной архив также сохраняет pilots отдельно.

## Границы интерпретации

Три seeds описывают только условный разброс при неизменном профиле. Для задержки указывается число применимых результатов: при отсутствии получений p99 не равен нулю, а неприменим. CI95 не рассчитывается для неполной группы. Меньший p99 среди немногих дошедших сообщений не означает лучшего обслуживания всего потока.

У федерации один служебный publisher на направление; у Relay отдельные экземпляры для разных источников. Сравнение включает разное число служебных соединений. Все доставки, включая drain, делятся на длительность подачи нагрузки: такой goodput когорты не является доказанной устойчивой пропускной способностью.

У профиля Mosquitto разные исходные точки N=16 и N=64. Дополнительные пересылки и fanout не калибровались; при QoS 1/2 исходная условная потеря повторно применяется на нескольких этапах. Эти результаты не подтверждают натурную точность федерации или ту же потерю у настоящего брокера при новой нагрузке. Отказоустойчивость, самоорганизация, CPU/RSS и EST не исследовались.

## Повторение

Собрать приложение по исходникам и версиям из плана. Отдельная точка повторяется командой `run --config <run>/run-config.json --output <новый-каталог>`. Полную программу запускает `python tools/federation/study.py run --work-dir <новый-каталог>`, независимую проверку — `verify` той же программы; окончательный отчёт строит `python tools/federation/report.py --work-dir <каталог>`. Для графиков нужен Matplotlib.

Исходная программа исполнения и отдельный генератор интерпретации сохраняются с хэшами. Повторное построение Markdown, таблиц, проверок и SVG проверено по байтам. Равенство хэшей подтверждает целостность; повторное вычисление и журналы обеспечивают проверяемость.

Этот набор относится к прежнему Relay с деревьями. Текущий сценарий tools/federation использует полносвязный Relay и отдельную публикацию. Для повторения этого набора используйте сохранённые исходники и сценарии его архива. Markdown отчёта сохранён побайтно под именем `Federation-study-bfs.md`; в реестре публикации обновлён только путь к нему и хэш этого пояснения. Первичные результаты и архивы прежней программы сохранены.
