# Пригодность Web для запуска модельных серий

Проверенная область: очередь Web запускает native-модели MqttRelay, федерации и балансировщика в отдельных процессах. На Linux выполнены девять комбинаций движка и QoS, затем три точных повтора. Все опыты завершились; двенадцать каталогов различаются, контрольные суммы файлов проверены, summary повторов совпали по байтам. Конфигурации проверялись до запуска первой точки.

Подтверждения: `reports/audits/web-ux-v3/series-receipt.json`, `browser-receipt.json`, `deployment-receipt.json`. Проверяемый код Web — `dd36b4d`; сборка выполнена из отдельного чистого checkout, отдельно от текущей разработки инструментирования статьи. Дополнительно прошли 33 Web-теста, 107 целевых интеграционных тестов и 12 браузерных сценариев на Linux.

Это техническое основание использовать Web как средство выполнения и сохранения модельной серии. Оно не подтверждает точность профиля относительно настоящего брокера, независимость натурного контроля или устойчивость всех возможных нагрузок. Натурные измерения по-прежнему выполняет MqttBenchmark.

Первая версия приёмочного скрипта ошибочно требовала 20 API-попыток при 20 запланированных публикациях. Балансировщик QoS 2 корректно показал 18 попыток и два случая backpressure. Исправлен проверяющий инвариант «попытки + backpressure = план»; модель, нагрузка и научные допуски не менялись. Исходный неуспешный receipt сохранён.

Что ещё необходимо для более полной работы:

- Сравнение нескольких выбранных запусков в одном окне с экспортом общей таблицы.
- Отмена/возврат редактирования графа и явное отображение несохранённых изменений.
- Разные профили на брокерах, разные параметры отдельных сетей и несколько брокеров в одной сети.
- Настройка произвольных подписок и прикладных маршрутов; текущие native-режимы создают свои служебные обмены и получателей.
- Исполнение произвольной структуры балансировщика.
- Долговременная контрольная точка для восстановления после остановки процесса; нынешняя пауза сохраняет состояние только в памяти.
- Интеграция внешних CLI-кампаний в мониторинг Web: сейчас это разные очереди.

Текущая область редактируемого исполнения — физический связный граф MqttRelay/федерации, промежуточные сети и размещение отправителей с общим профилем и параметрами сети. Сохраняются имена сетей, брокеров и отправителей; граф не подменяется исходным шаблоном. Для каждой серии научные условия и ограничения следует фиксировать отдельно.

Выбор сохранённых топологий вынесен из вкладки «Файлы» в постоянно видимую верхнюю панель редактора. Исправление `d71b4fd` развёрнуто отдельным release; данные сохранены. Подтверждения — `reports/audits/web-selector-v4/`. Натурная серия статьи 1 и одиночный профилированный BrokerFidelity выполняются отдельным контроллером; эта Web-приёмка не означает поддержку их полного запуска из интерфейса.
