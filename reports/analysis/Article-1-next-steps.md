## Что можно делать без Linux параллельно

Сопоставить вклад с публикациями, подготовить вопросы независимому проверяющему, проверить согласованность выводов диссертации с новой узкой серией. Для второй статьи готов вспомогательный [пакет 54 опытов](Article-2-evidence-package.md). Основная сеть имеет сохранённое покрытие 106/162 и 0/6 повторов; для следующего анализа потребуются её собственные первичные файлы. Данные первой статьи не заменяют сетевые результаты.

## Что остаётся для Web

После включения Linux установить проверенную версию с поддержкой `single-point-v1`, сохранить задания и топологии, затем выполнить короткую проверку нового профиля через Web и сопоставить научные файлы с прямым исполнителем. Основная серия этой статьи уже завершена прямым Probe; повторять всю серию ради проверки оболочки не требуется. Натурные измерения по-прежнему выполняет MqttBenchmark.
