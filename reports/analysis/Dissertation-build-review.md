## Обнаруженная неоднозначность

В `diss` есть несколько вариантов текста. `README_Сборка.md` описывает **`latex/Dissertation.tex`**, извлечение текста из DOCX и старые абсолютные пути. Это другой вход, не инструкция воспроизводимой сборки основного `dissertation.tex`. Запуск генератора DOCX не нужен для этой проверки и мог бы изменить защищённый текст; он не выполнялся.

Основной документ использует `memoir`, XeLaTeX, настройки из `common` и `Dissertation`, библиографию `biblatex`/Biber и файлы `biblio/external.bib`, `author.bib`, `registered.bib`. По умолчанию выбран набор шрифтов Microsoft. Полный консервативный список пакетов из всех отслеживаемых TeX-файлов сохранён в проверке; это **не доказательство наличия всех транзитивных зависимостей** и не точный список пакетов только основной сборки.

## Воспроизводимая команда

На машине с установленными TeX-инструментами и утилитами Poppler:

```text
python tools/dissertation/check_dissertation_build.py --build --output <новый-каталог-вне-diss> --timeout 300
```

Инструмент создаёт отдельный снимок и запускает в нём:

```text
latexmk -norc -r latexmkrc -pdfxe -interaction=nonstopmode -halt-on-error -file-line-error dissertation.tex
```

Унаследованные переменные, меняющие режим, шрифты или библиографию, убираются: действуют настройки исходников. Старые PDF и промежуточные файлы не копируются. Команда, версии программ, хэши входов, журнал, код выхода и неизменность исходников сохраняются в `verification.json`. При тайм-ауте завершается дерево дочерних процессов сборки.

При успешной компиляции отдельно проверяются: наличие нового PDF, число страниц и извлекаемый текст, фактическая загрузка всех верхнеуровневых разделов по `.fls`, непустая библиография `.bbl`, неразрешённые ссылки и цитаты, отсутствующие символы и запросы повторного прохода в финальном журнале. Успех этих проверок **не заменяет визуального просмотра** и не подтверждает научную корректность.

## Изолированная portable-попытка

Дополнительно проверен официальный Tectonic 0.17.0 без глобальной установки. Исполняемый файл, снимки и кэш находятся только в игнорируемом `MqttBenchmark/artifacts/dissertation-build-v1/`. ZIP и бинарь не предназначены для Git. SHA-256 ZIP совпал с `digest` официального GitHub API release; отдельная криптографическая подпись поставщика не проверялась.

Первая попытка завершилась до TeX: `could not open format file latex / Access is denied (os error 5)`. Это соответствует открытой проблеме Tectonic: каталог `latex/` рядом с входом на Windows ошибочно принимается за формат. Во второй изолированной копии исключён только неиспользуемый основным текстом альтернативный каталог `latex/`; список исключений сохранён, исходный репозиторий не менялся. Промежуточный отказ вспомогательного скрипта при повторном создании временного каталога исправлен до повторного запуска движка; научные входы не менялись.

Бюджет portable-проверки: общий локальный объём до 300 МБ; сторож завершает процесс при 240 МиБ, оставляя запас. Два запуска движка ограничены суммарно примерно пятью минутами. Это ограниченная проверка возможности сборки, а не разрешение устанавливать полную TeX-среду.

**Вторая попытка закончилась подтверждённым отказом внешнего Biber:** `Running external tool biber ... error: program not found`. Первый проход основного TeX завершился: в журнале указаны все 13 верхнеуровневых разделов и `Output written on dissertation.xdv (113 pages, 2221808 bytes)`. Это промежуточное представление, **не готовый PDF**. Два запуска двигателя заняли суммарно 270,5 с; объём отдельного дерева составил 198,3 МБ. Сторожевые ограничения не сработали.

Из фактического журнала установлены `biblatex 3.17`, `biblatex-gost 1.22`; для продолжения нужна совместимая версия внешнего Biber. Внешние предупреждения Tectonic о чтении Windows-шрифтов не игнорируются: сохранены хэши 17 фактически прочитанных файлов. Переносимость требует того же набора/версий шрифтов либо отдельно согласованного изменения оформления. Подмена Times New Roman другим шрифтом в этой проверке не выполнялась.

Предупреждения о цитатах и ссылках после первого прохода ожидаемы до Biber и повторных проходов; считать их окончательно проверенными нельзя. Точное состояние сохранено в `reports/audits/dissertation/dissertation-build-v1/portable-002-verification.json`, полный вывод — в `portable-002.stdout.log`, TeX-журнал — в `portable-002.dissertation.log`, хэши шрифтов — в `fonts-observed.json`.

Официальные источники: [release Tectonic](https://github.com/tectonic-typesetting/tectonic/releases/tag/tectonic%400.17.0), [Windows-ошибка каталога latex](https://github.com/tectonic-typesetting/tectonic/issues/1344), [настройка отдельного кэша](https://tectonic-typesetting.github.io/book/latest/getting-started/first-document.html), [внешний Biber и совместимость версий](https://tectonic-typesetting.github.io/book/latest/ref/v2cli.html).

## Что требуется для закрытия шага

1. Обеспечить версионированную TeX-среду с XeLaTeX, совместимыми `biblatex-gost`/Biber, `latexmk`, `makeindex`, Poppler и нужными шрифтами. Перечень пакетов и версий уточняется по фактическому успешному журналу, не только по поиску в исходниках.
2. Выполнить команду для основного входа в новом каталоге и устранить только подтверждённые ошибки сборки, сохраняя каждую попытку. Изменения текста согласуются отдельно.
3. Проверить ссылки, цитаты, библиографию, шрифты и все главы. Просмотреть титульный лист, оглавление, формулы, таблицы, рисунки и приложения в свежем PDF.
4. Сохранить PDF, журнал, manifest зависимостей и команду; повторить сборку в той же среде. Сравнить содержимое и структуру, явно отделяя изменяемые PDF-метаданные от текста.

До этого факт наличия старого PDF или прохождение тестов Python не является основанием принимать шаг 37.
