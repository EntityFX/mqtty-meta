# Одноточечный профиль для новой проверки статьи 1

Добавлен явный формат покрытия `single-point-v1`: один выбранный брокер, 16 байт, QoS 1, 16 отправителей и три натурных повтора. Это подготовка к новой калибровке; сами новые калибровочные измерения ещё не выполнены.

Калибратор создаёт артефакт `broker-calibration-single-point-v1`. Эмпирический профиль сохраняет его внутри прежней оболочки версии 4, вместе с точным снимком гистограмм и SHA. Пример использования после получения настоящих входов:

```text
EntityFX.MqttY.MqttRelay.App calibrate --observations <observations.json> --latency-histograms <histograms.json> --broker <broker> --coverage-protocol single-point-v1 --mqtty-repository <clean-repository> --output <new-profile.json>
```

При отсутствии режима запуск отвергается: данные для 16 отправителей не заменяют данные для одного или 64, а QoS 1 не заменяет QoS 0/2. Прежние полные и compact-профили по-прежнему требуют прежнюю сетку. В одной группе профилей нельзя смешивать разные покрытия.

В синтетических тестах проверены неправильное число повторов, отсутствие/дублирование точки, другая реализация брокера, неподдерживаемые размер/QoS/число отправителей, изменение покрытия и ёмкости. Отдельно проверены происхождение гистограмм, SHA и объединение с весами по числу завершений. Три разных размера выборки дают распределение по 6000 событиям; равное усреднение трёх распределений дало бы другой проверяемый результат и отвергается тестом.

Один и тот же эмпирический профиль исполнен прямым runner и Web-адаптером: научные файлы совпали побайтно, фазы и журналы ID сохранены. Неподдерживаемое число отправителей отвергается до запуска. Независимый контроль требует отдельной серии и явного совпадающего покрытия; профиль по контролю не перестраивается.

Прошли **96 выбранных интеграционных проверок**, включая **28 случаев нового формата**, и **39 тестов всего Web-проекта**. Полный интеграционный набор этим не заявляется. Первые положительные тесты отказали на неподдерживаемом формате до изменения кода; промежуточный отказ нового CLI-теста из-за незаданных обязательных параметров сохранён, тестовые входы исправлены без ослабления проверки.

[Квитанция и SHA тестовых результатов](../audits/dissertation/article-1-single-point-profile-v1/verification.json). Код MqttY: `4c658536586f88a89cd3ff5ab0915903640cf3c9`, опубликован в develop. Эти проверки выполнялись локально; работающий Linux Web и его замороженный runtime не заменялись. Перед новой серией нужно отдельно установить и зафиксировать согласованную версию.

Открыты оценка расходов записи событий при неизменной нагрузке, выбор общего окна до контрольных измерений и сама калибровка. Основная программа остаётся **0/40, без допуска**. Тесты формата не являются измерением точности брокера.
