Числа короткой серии и сводка покрытия не изменились; обновлены статья, схемы и подписи. Пакет v1 ниже сохраняет прежний снимок. Отдельно оформлена [приёмка основной сети](Article-2-main-acceptance.md); новых измерений и обращения к Linux в этом продолжении не было.

Подготовлен самостоятельный блок для шагов 23–24 исходного [плана](../../docs/dissertation/articles-and-work-plan.md). Он позволяет использовать завершённую короткую серию и явно показывает границы основной. Новых расчётов на Linux не было; исторические данные и критерии не изменены.

## Что проверено сейчас

- В `runs.json` найдены ровно 54 различных сочетания: две модели × три режима × три QoS × три seed. Набор ID совпал с сохранённой программой.
- Для каждой сводки заново проверены исходные попытки и завершения по отправителям, ожидаемые пары как «попытки × получатели», уникальные доставки по получателям, недоставка, скорости, суммы до и после прекращения нагрузки и принятые/отклонённые пересылки. QoS 0 не получает выдуманного ACK.
- Для 18 групп восстановлены 378 значений `n`, среднего и CI из сохранённых строк; расхождений нет. Интервал по seed относится к модели, не к ошибке реального брокера. При двух применимых p99 интервал не подставлен как для трёх наблюдений.
- Сохранённая квитанция сообщает о шести совпавших повторах короткой серии. Заново эти повторы и первичные журналы ID здесь не исполнялись и не проверялись.
- Для основной кампании независимо проверена арифметика покрытия: 106/162, неподтверждены 56 точек, из них две с нерешённой технической ошибкой. 109 попыток минус три отказа дают 106 подтверждённых результатов; повторов 0/6. Предупреждений 16.

## Ограниченный обзор готовности

Область проверки — Markdown-рукопись и компактные сохранённые данные. Это проверка связей утверждений с числами; не независимое научное чтение человеком, не проверка библиографии и не допуск к подаче. Отсутствуют полные локальные результаты основной матрицы, её покомпонентное покрытие и повторения. Этим пакетом нельзя закрыть шаг 23 (1,5 дня) или 24 (1 день) целиком. Подготовлен законченный вспомогательный результат, дополнительного веса в исходном плане ему не приписываем.

Следующий самостоятельный шаг для сетевой статьи — снять существующие результаты 106 точек с Linux, проверить ID и первичные журналы и строить сравнение лишь по полным тройкам режимов при одинаковых условиях. Это работа с уже рассчитанными данными, без нового измерения и без перезапуска кампании. Если часть нужных файлов отсутствует, оформить точное фактическое покрытие; не подменять его старой короткой серией.

## Воспроизведение

```text
python -m unittest discover -s tools/dissertation -p test_article2_evidence_package.py
python tools/dissertation/article2_evidence_package.py --output <новый-каталог>
```

Пять тестов на известном примере проверяют несколько получателей, завершения после подачи, неверный знаменатель, QoS 0 и различие попыток от условий. Пакет требует новый каталог и не перезаписывает прежний. Только стандартная библиотека Python, сеть не требуется.
