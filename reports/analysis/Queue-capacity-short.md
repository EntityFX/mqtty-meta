# Короткая пара очередей: данные приняты, перегрузка не возникла

Короткий опыт завершился за **94,98 с** обычного времени. Оба процесса вернули код 0; их первичные данные независимо пересчитаны локально. Между входами менялась только выходная очередь федератора: 1024 → 4096. Общие окна обеих моделей — 0,25 с прогрева, 2 с подачи и до 10 с ожидания, tick 0,1 мс, seed 42. Полная программа и критерий интерпретации были заданы [до запуска](../../docs/dissertation/queue-capacity-short-protocol.md).

| Показатель | Очередь 1024 | Очередь 4096 |
| --- | ---: | ---: |
| Исходных попыток и завершений | 2000 | 2000 |
| Ожидаемых / уникальных доставок | 8000 / 8000 | 8000 / 8000 |
| Доставок после прекращения подачи | 3312 | 3312 |
| Недоставка / дубликаты | 0 / 0 | 0 / 0 |
| p99 доставки, мс | 1510,3 | 1510,3 |
| Переполнений очереди | 0 | 0 |
| Логических экспортов | 18000 | 18000 |
| Подавленных повторных сообщений | 12000 | 12000 |

Шесть научных файлов двух вариантов совпали побайтно. Это совпадение результатов при двух разных входных размерах очереди; оно не является точным повтором с полностью одинаковым входом. Все 2000 сообщений получили четыре подписчика. Нулевая недоставка при p99 около 1,51 с не означает небольшой задержки.

**Пара неинформативна для проверки перегрузки:** даже исходная очередь 1024 не переполнилась. Это предусмотренная классификация `completedWithoutBaselineOverflow`. Из такого результата нельзя заключить, что увеличение очереди исправляет потери основной десятисекундной серии. Организация выходов Relay и федератора также не выровнена. Новую нагрузку автоматически не увеличивали; нового опыта не запускали.

## Перенос и сохранность

Перенесены **77 файлов, 31 008 508 байт** до сжатия. Размер и SHA каждого совпали с Linux. Архив остаётся вне Git: `C:/temp/mqtty-evidence/queue-capacity-short-v2-20261029/raw-001.tar.gz`, SHA `2dbabbb350ed110d8adc22595c91a338a3f17e70b62035df9c20ab270adb582b`.

Проверены 24 закреплённых файла запуска и все 281 файла исходного frozen manifest. Прежняя длинная пара с таймаутом 4096 сохранена отдельно; её неудачную попытку эта короткая программа не исправляет задним числом. [Приёмка](../audits/dissertation/queue-capacity-short-v2/acceptance.json), [команда пересчёта](../audits/dissertation/queue-capacity-short-v2/accept.py), [перенос](../audits/dissertation/queue-capacity-short-v2/transfer.json).

При получении данных Linux оказался перезагружен, а hd250 — не смонтирован. Диск сначала подключили только для чтения; файлы и законченный результат обнаружены на месте. Исчезновение transient-службы после перезагрузки не трактовалось как падение научного опыта. Для отдельного восстановления Web затем потребовалась запись в его рабочие каталоги; научные входы не менялись. [Диагностика](../audits/dissertation/queue-capacity-short-v2/storage-diagnosis.json).

Техническая приёмка пары завершена. Причинный вопрос о переполнениях основной сети остаётся открытым; дополнительный короткий опыт не получает новый вес в исходном плане диссертации.
