# Архив документации

На 03.11.2026 промежуточные планы, повторные обзоры и старые задания на замеры убраны из рабочей навигации. Их точные версии остаются в Git на коммите `8b27518e1d206f90d2da4fbac0aa30c542834803`. Это архив, а не действующая очередь задач.

[Реестр сокращения](../status/documentation-consolidation-20261103.json) содержит для каждого удалённого документа путь, SHA-256, ссылку на исходник и основной действующий раздел. Полный текст не дублируется в новом формате. Для просмотра файла без изменения рабочей ветки:

```powershell
git show 8b27518e1d206f90d2da4fbac0aa30c542834803:docs/overview/ExpertReview.md
```

Рабочие входы: [каталог документации](../../docs/README.md), [план завершения](../../docs/plans/completion.md), [статус](../status/Progress.md), [Web](../web/README.md), [принятые результаты](../README.md).

Числовые данные, JSON/CSV, рисунки, исходные квитанции и скрипты сохранены. Старые протоколы и генераторы отчётов воспроизводятся на соответствующей версии Git: генератор может заново создать убранный промежуточный Markdown. Документы, включённые в реестры публикационных хэшей, сохранены побайтово, даже если они описывают прошлую серию. Поэтому отдельные исторические файлы остаются в своих прежних каталогах.

Сокращение касается отслеживаемых Markdown метарепозитория. Подмодули и локальные игнорируемые архивы не входят в его счётчик и не очищались.
