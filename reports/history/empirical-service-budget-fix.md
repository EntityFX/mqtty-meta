# Исправление времени обслуживания и подачи нагрузки в MqttY

Проверенная версия: `115885e012053d0112413e07743b061369ebea93`. Допуски сохранены: RPS — 15%, p99 — 20%, абсолютная разность долей ошибок и недоставки — 0,05.

## Какие ошибки исправили

| Проблема | Изменение |
| --- | --- |
| RTT ошибочно использовался как полное время завершения публикации | В режиме `empiricalServiceBudget` время MQTT-обмена согласовано с калибровочным распределением задержек |
| Короткие всплески создавали искусственные отказы ограничителя скорости | Для одиночного двойника в режиме ожидания предыдущей публикации введено ожидание доступной производительности |
| QoS 0 ограничивался одним событием на обновление модели | За шаг могут быть созданы все публикации, соответствующие накопленной заданной нагрузке |
| При ограничении очереди отправителя терялась дробная часть интенсивности | Дробная часть сохраняется; систематическое округление скорости устранено |

Время ожидания доступной производительности и остаточная эмпирическая задержка объединяются максимумом. Их сложение повторно учитывало бы очередь, уже присутствующую в измеренном распределении.

Это предположение об агрегированной модели. Оно не определяет внутреннее устройство очередей настоящего брокера. Режим применяется к одиночному BrokerFidelity с `closedLoopPerPublisher`; для Relay сохранён прежний способ моделирования.

## Почему остались три нарушения p99

p99 трёх натурных повторов после округления гистограмм: 3,771; 3,776; 6,827 мс. Их среднее — около 4,791 мс. p99 всех сообщений, объединённых в одну выборку, — около 3,799 мс.

Модель использует объединённое распределение и дала 3,79; 3,80; 3,78 мс. Проверка сравнивает эти значения со средним p99 повторов. Это разные статистические величины. Несоответствие сохранено как нарушение; эталон не заменялся после получения результата.

Для следующего протокола нужно заранее выбрать одну и ту же оцениваемую величину для натурного опыта и модели. Подгонка модельной задержки под удобное число не решает эту методическую проблему.
