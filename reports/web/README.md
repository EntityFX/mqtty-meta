# MqttY.Web: подтверждённое состояние и приёмка релиза

Сводка на 03.11.2026 по сохранённым квитанциям. Развёрнутые ранее версии прошли технические проверки; доступность сервера сейчас не проверялась. Готовность нового релиза определяется критериями W1–W5 в [плане завершения](../../docs/plans/completion.md), а не количеством прежних запусков.

| Подтверждение | Результат | Источник |
| --- | --- | --- |

| Основные действия в браузере | 12 сценариев: редактирование/сохранение графа, соединения сетей, пресеты, запуск, статистика и выгрузки; `passed=true`, ошибок браузера нет | [browser-receipt.json](../audits/web-ux-v3/browser-receipt.json) |
| Обновление службы | Health до/после, прежние данные сохранены, научная кампания не перезапущена | [deployment-receipt.json](../audits/web-ux-v3/deployment-receipt.json) |

| Связь с натурным контролем | Отдельные проверки профиля и контроля, с собственными версиями и границами | [Натурный контроль / Web](../analysis/Article-1-native-control-web.md), [валидация](../analysis/Article-1-web-validation.md) |

Исходная неудачная проверка не удалена: [initial-harness-receipt.json](../audits/web-ux-v3/initial-harness-receipt.json). Для QoS 2 исправлялся критерий `planned = attempts + backpressure` (18 + 2 = 20), а не результат модели. Техническое завершение задания не доказывает точность симуляции реального брокера.

Поддерживается связный физический граф relay/federation с промежуточными сетями и размещением клиентов; общий профиль и сетевые параметры. Произвольный граф load-balancing и полное управление натурными кампаниями через Web не заявлены. Натурные измерения выполняет MqttBenchmark; Web запускает модели. CPU/RSS процесса — стоимость исполнения, а не измеренные ресурсы моделируемого брокера.

Для приёмки нужен один зафиксированный кандидат из `develop`, короткая проверка пользовательского пути, экспорта и жизненного цикла службы, затем ручное решение пользователя. Руководство: [развёртывание на Linux](../../docs/mqtty/web-deployment.md). Дополнительные научные матрицы в этот этап не входят.
