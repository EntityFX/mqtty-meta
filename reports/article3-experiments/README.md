# Статья 3: Эксперименты по моделированию сельскохозяйственной IoT-архитектуры

Этот каталог содержит конфигурационные файлы и скрипты для запуска экспериментов в MqttY Federation.App по статье 3 ("Моделирование крупной сельскохозяйственной IoT-архитектуры в MqttY").

## Архитектура

```
Поле A (5–10 оросительных установок) → Полевой брокер A → Региональный брокер 1
Поле B (5–10 оросительных установок) → Полевой брокер B → Региональный брокер 1
Поле C ...                                                      → Региональный брокер 2
Поле D ...                                                      → Региональный брокер 2
                                                              ↕
Региональный брокер 1 ⇄ Региональный брокер 2 (отказоустойчивая связь)
```

## Эксперименты

| Файл | Топология | Режим | Регионы | Поля | QoS | Описание |
|------|-----------|-------|---------|------|-----|----------|
| `exp-1-star-config.json` | Star | Federation | 4 | 12 | 1 | Базовая доставка через одного регионального брокера |
| `exp-2-ring-config.json` | Ring | Federation | 4 | 12 | 1 | Отказоустойчивость кольца |
| `exp-5-relay-config.json` | Star | Relay | 4 | 12 | 1 | Режим Relay (без подавления дублей) |

Параметры:
- 4 региональных брокера, 3 поля на регион, 12 полей всего
- ~7 оросительных установок на поле, ~90 установок всего
- Полезная нагрузка 16 байт, частота 1000 сообщений/с
- Время измерения 30 с, прогрев 1 с, drain 5 с
- Seed 42 для детерминизма

## Сетевые параметры

| Канал | Пропускная способность | Задержка | Потери | Очередь |
|-------|----------------------|----------|--------|---------|
| Поле → Регион (мобильный IoT) | 500 Кбит/с | 100 мс | 5% | 1024 |
| Регион → Регион | 10 Мбит/с | 20 мс | 0.5% | 4096 |

## Запуск

### Предварительные требования

- .NET 6 SDK и runtime
- Исходный код MqttY (проект `EntityFX.MqttY.Federation.App`)

### Запуск отдельного эксперимента

```bash
dotnet run --project src/EntityFX.MqttSimulator/EntityFX.MqttY.Federation.App -c Release -- \
  demo --brokers 4 --topology star --mode federation --publishers 48 --qos 1 --rps 1000 --seconds 30 --seed 42 \
  --output results/exp-1-star
```

### Запуск всех экспериментов

```bash
bash run-all-experiments.sh
```

Результаты сохраняются в `results/article3/`.
