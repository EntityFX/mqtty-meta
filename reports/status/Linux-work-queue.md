Полный повтор 576 натурных измерений сейчас не требуется: их первичные события уже пересчитаны. Перенос натурного стенда на другое оборудование, обратная двухмашинная схема и новая калибровка — отдельные эксперименты, а не скрытая часть остатка текущей серии. Для точности десятиброкерной сети с single/N=160 потребуется новая натурная точка и согласованное расширение профиля; имеющиеся N=128/64 не подставляются вместо неё.

Время будущей сетевой матрицы станет известно после pilots; переносить на неё 20-часовую оценку BrokerFidelity нельзя. Сейчас её конфиги только проверены локальным CLI: **252/252 valid, выполненных симуляций 0**. На Linux эта программа не запущена и автоматически после текущей службы не стартует.

## Следующее продолжение

1. Проверить текущую чувствительность вручную **24 октября около 09:00 МСК**, либо раньше при сообщении об ошибке. Не перезапускать живую службу ради чтения progress.
2. После завершения скачать компактные результаты, сверить hashes, отделить технические отказы от failed критериев, выполнить сравнение вариантов и подготовить таблицы/графики для автора.
3. Runner реализован и локально проверен: 68 тестов и окончательный smoke 15/15 с настоящим MqttY CLI. Следующая проверка — реальный Linux mount/cgroup и изоляция; затем зафиксировать clean commits и snapshot runtime на целевой машине до нового опыта.
4. Запустить отдельную Linux-серию pilots. После подтверждения долгого фонового запуска обновить Progress.md и закончить работу агента; сам расчёт продолжает работу.

Linux в последующем блоке не опрашивался; счётчики и прогноз выше не обновлялись. Реализован [оркестратор](../../docs/dissertation/network-runner.md).
