## Данные и сохранность

Научные CSV/JSON, графики, конфигурации и квитанции находятся в `data/` и `audits/`. Они сохраняются по прежним путям: на них ссылаются проверки, статьи и пакеты воспроизведения. Не удаляйте их как устаревшие рабочие заметки.

| Реестр | Содержание |
| --- | --- |
| [Первичные архивы](data/archive-registry.json) | Успешные и неуспешные попытки исторической программы |
| [Внешние архивы](data/external-archives.json) | Пути, размеры и контрольные суммы больших наборов вне Git |
| [Натурные данные](data/native-evidence.json) / [модельные](data/model-evidence.json) | Исторические агрегаты и происхождение |
| [Перенос документации](data/documentation-layout-v1/manifest.json) | Прежние пути и защищённые файлы |
| [Сокращение документов](status/documentation-cleanup.json) | Удалённые рабочие планы, закреплённая версия Git и проверки |

Отчёт описывает состояние на свою дату. Живой процесс подтверждается отдельно службой/PID и progress; опубликованный снимок не является мониторингом.
