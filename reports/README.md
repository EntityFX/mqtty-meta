## Основная кампания

Выполнено **1512 основных запусков**: 576 натурных измерений, 576 BrokerFidelity/holdout и 360 сетевых симуляций. Pilots, retries и диагностика сохраняются отдельно и не прибавляются к успешному покрытию.

Начните с [микроотчёта о выборе брокера](mqtt-benchmark/Best-broker.md), затем [сравнения по метрикам и EST](mqtt-benchmark/Broker-comparison.md) и [проверки MqttY/MqttRelay](mqtty/validation/Model-validation.md).

Полнота программы не означает точность модели: ни один двойник не прошёл все независимые сценарии. Натурная точность Relay-сети этой кампанией не установлена. [Оценка достоверности и верифицируемости](mqtty/validation/Evidence-assessment.md) отделяет арифметическую проверку, повторяемость и соответствие натурным наблюдениям.

## Данные и происхождение

| Материал | Назначение |
| --- | --- |
| [Натурные результаты](data/native-evidence.json) | 576 выбранных успешных измерений и provenance |
| [Модельные результаты](data/model-evidence.json) | Одиночные и сетевые симуляции |
| [Наблюдения и источники](data/snapshot.json) | Исходные campaign identities и SHA-256 |
| [Реестр raw-архивов](data/archive-registry.json) | Все зарегистрированные первичные архивы, включая неудачные попытки |
| [Внешние архивы](data/external-archives.json) | Пути, размеры и SHA-256 полных доказательств на выделенном диске |
| [Повторяемость](data/replay-results.json) | Сохранённые проверки выбранных повторных симуляций |
| [Интегральная оценка](data/integral-assessment.json) | EST и анализ чувствительности |
| [Контрольные суммы публикации](publication-sha256.json) | Целостность опубликованных файлов |
| [Реестр переноса документации](data/documentation-layout-v1/manifest.json) | Прежние/новые пути, исходные хэши и сохранённые предыдущие реестры публикации |

Данные в `reports/data` и исходные архивы не менялись при упорядочивании документов. Изменены размещение отчётов, ссылки и контрольные суммы их новой документальной редакции. Архивы ZIP/TAR хранятся вне Git. Историческая версия отчёта не становится новым экспериментом после переноса.

HTML содержит встроенные графики и работает без интернета; ссылки на CSV/JSON требуют остальных файлов набора. Каталоги данных остаются на прежних местах, чтобы сохранить идентичность научных входов.

Новая машина и новая серия: [руководства MqttBenchmark](../docs/mqtt-benchmark/README.md). Симуляции: [руководства MqttY](../docs/mqtty/README.md). Для проверки текущего процесса нужны служба/PID и его актуальный протокол; опубликованный отчёт является снимком результатов.
