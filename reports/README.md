## Где находятся данные

`assets/` содержит графики, файлы CSV — численные таблицы. `data/` содержит снимок агрегатов, модельных итогов, настроек и сведений о происхождении. [Снимок и SHA-256](data/snapshot.json) фиксируют, какие файлы прочитаны при публикации; сбор снимка занимает некоторое время и не является атомарной копией всей работающей серии.

Подробные журналы сообщений остаются на диске результатов. [Реестр архивов](data/archive-registry.json) содержит пути и контрольные суммы. Восстановление архивов ранее выполнено контроллером; публикация документов не считается новой проверкой всех исходных данных.

HTML содержит встроенные графики и открывается без интернета. Для перехода к JSON, CSV и инструкциям рядом нужен остальной каталог отчётов и документация.

## Обновление публикации

`python tools/campaign/publish-broker-reports.py --output reports` пересоздаёт частичные таблицы, графики и HTML из сохранённого снимка. Скрипт проверяет контрольные суммы источников и формулу CI95. Он не запускает измерения.

Для нового снимка используйте `--source <каталог controller> --evidence-root <корень доступных архивов> --output <новый каталог>`. Существующий снимок не перезаписывается. Новый результат сначала проверяют, затем обновляют опубликованные выводы и документы о брокерах.
