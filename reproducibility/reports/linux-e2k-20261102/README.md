## Сценарии и наблюдения

Один брокер, один издатель и один подписчик, `brokerFidelity`, lookup по двум
`connectedClients`. Два режима брокера: ideal и legacy Mosquitto v2. Payload
16 байт; seed 42; QoS публикации и подписки одинаковый; `parallel=false`.
Тик 0,1 мс; прогрев 0,1 с; измерение 1 с; drain до 2 с виртуального времени.
Исходная нагрузка 1000 публикаций/с. Каждый сценарий запускался дважды в отдельном
процессе с одной конфигурацией. Полные параметры сохранены в `config.json` каждого сценария.

Таблица показывает один повтор; второй совпал. P99 округлён только для отображения,
исходные JSON и их fingerprints не округлялись.

| Модель | QoS | Attempted | Completed | Publish failed | Delivered | P99, мс | Совпадение с Windows |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Ideal | 0 | 1001 | 1001 | 0 | 1001 | Не применимо | Да |
| Ideal | 1 | 1001 | 1001 | 0 | 1001 | 0,3 | Да |
| Ideal | 2 | 1001 | 1001 | 0 | 1001 | 0,9 | Да |
| Legacy Mosquitto v2 | 0 | 1001 | 951 | 50 | 951 | Не применимо | Да |
| Legacy Mosquitto v2 | 1 | 1001 | 1001 | 0 | 1001 | 1,1 | Да |
| Legacy Mosquitto v2 | 2 | 1001 | 1001 | 0 | 1001 | 2,2 | Да |

Во всех случаях `rateRejected=0`, `deliveryDropped=0`, `deliveryLossRate=0`.
В legacy QoS0 доля отказов публикации — `50/1001`, около 4,995%; она воспроизвелась
точно. Счётчик attempted равен 1001 при номинальной нагрузке 1000/с и окне 1 с.
Это значение сохранено без поправки и совпадает с Windows. Причина дополнительного
учёта на границе фаз в этой работе не исследовалась; корректность измерительной
границы требует отдельной проверки. Совпадение двух платформ само по себе её не доказывает.

## Что именно проверено

Для всех 12 исходных bundles повторно вычислены fingerprints полной summary,
брокерной части counters, полной latency histogram, фаз и подключений из manifest,
а также конфигурации. Значения сравнивались строго; допуск и округление не применялись.
Сортировка ключей и JSON-форматирование нормализовались по исходному runner.

В `comparison.json`: `allLocalRepeatsMatch=true`,
`allScientificFingerprintsMatch=true`, `allRuntimesMatch=false`.
Во всех шести строках `differentFields` содержит только `runtime`.
Поля времени, ОС, CPU, строковый dump общих counters и файлы топологии не входят
в критерий равенства. Они сохранены как исходные артефакты.

Индивидуальные ideal-запуски вернули CLI-код 0, legacy-запуски — код 3:
reference RPS не пройден во всех трёх legacy-сценариях; reference p99 дополнительно
не пройден при QoS1/2. Эти статусы сохранены и не считаются ошибкой replay.
Предварительный профиль `provisional-legacy-v1` не даёт основания заявлять fidelity.

## Область готовности

**Готов ограниченный smoke-набор на Windows x64 и ALT Linux/e2k.**
Не проверены расширенная матрица с payload 256 и seeds 43/44, другие runtime,
нагрузки, масштабные топологии и натурные брокеры. Для multi-broker Relay ранее
найдено расхождение между процессами, сохранённое в `../../relay-process-mismatch.json`;
оно этим прогоном не исправлено. Нет lockfile NuGet и гарантии побайтовой
пересборки бинарников. Два повтора на сценарий доказывают наблюдаемое совпадение
этих запусков, но не общую детерминированность всех возможных сценариев.
